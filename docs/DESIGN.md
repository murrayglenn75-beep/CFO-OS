# Product & Visual Design Direction

## Design goal

CFO OS should feel like a **financial control room**, not a generic SaaS dashboard and not an AI chat wrapper.

The hierarchy is:

1. close state and decision readiness,
2. booked financial outcomes,
3. variances and exceptions,
4. evidence / trust state,
5. AI explanation,
6. action controls.

## Visual system

- Dark graphite foundation with high-contrast neutral type.
- Acid-lime accent reserved for verified/primary system state rather than decoration.
- Amber for review-required states, red for blocked/negative states, violet for model estimates.
- Compact mono labels for audit IDs, source state and control metadata.
- Large executive numbers, but fewer KPI cards than conventional dashboards.
- Evidence metadata stays visually subordinate until a claim needs inspection.

## Key screen concepts

### Command Center
A close-readiness score, four essential finance KPIs, one trend surface, an executive decision brief, evidence state and close checklist.

### Governed Copilot
Conversation remains central, but every AI response can expand into a Trust Envelope rather than showing a generic “AI generated” badge.

### Trust & Security
A visual authority path explains why confidence is not permission. A policy simulator demonstrates how role, evidence and close state can block an action even when the model recommends it.
