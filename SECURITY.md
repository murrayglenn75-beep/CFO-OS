# Security Policy

CFO OS is a public synthetic portfolio demonstration, not a production financial service.

The v2.1 public build includes authenticated identity, organization membership, server-resolved tenant roles, PostgreSQL Row Level Security, governed AI controls, and deterministic action qualification.

Please do not submit real credentials, account data, personally identifiable information, or confidential financial records to a public deployment of this repository.

Security issues in the public code can be reported through the repository's GitHub issue/security facilities. Do not include real secrets in a report.

The public build does not claim prompt-injection immunity, formal verification, compliance certification, or production-grade durable audit storage.

See [`docs/SECURITY.md`](docs/SECURITY.md), [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md), and [`docs/VALIDATION.md`](docs/VALIDATION.md) for implemented controls, validation scope, and explicit limitations.
