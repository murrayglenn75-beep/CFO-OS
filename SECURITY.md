# Security Policy

CFO OS is a public portfolio demonstration, not a production financial service.

Please avoid submitting real credentials, account data, personally identifiable information or confidential financial records to a public deployment of this repository.

Security issues in the public code can be reported through the repository's GitHub issue/security facilities. Do not include real secrets in a report.

See [`docs/SECURITY.md`](docs/SECURITY.md) and [`docs/THREAT_MODEL.md`](docs/THREAT_MODEL.md) for the implemented controls and explicit limitations.
